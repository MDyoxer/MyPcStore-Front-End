## Reglas de uso (resumen)

- El crédito de arriba debe mostrarse visiblemente junto al modelo (pie de página o sección donde se exhibe).
- No se puede sugerir que el autor respalda este proyecto.
- Si el archivo se modifica (compresión, reescala, recolor), actualizar el campo **Cambios realizados**.
